OSSM M5 Remote Web Flasher

Flash firmware directly from your browser with USB. No PlatformIO setup needed for end users.

Use Chrome or Edge. USB data cable required.
Steps:
  1. Connect your M5 with a USB data cable.
  2. Select the correct board above.
  3. Click Install and select the serial/COM port.
  4. Wait for flash to complete, then reboot the device.
Safety note: verify you selected the correct board type before flashing. Flashing the wrong target can fail or create unstable behavior.
Firmware files are sourced from this repository build artifacts.
